# 在线服务：客户端与页面

> 状态：计划（待实施）。接口契约见 [在线服务-服务端设计.md](在线服务-服务端设计.md)，部署与验收见 [在线服务-部署与验收.md](在线服务-部署与验收.md)。

## 一、版本与自动更新

- `scripts/build.sh` 生成 `BUILD_TAG` + `APP_VERSION`（package.json）+ `BUILD_CODE`（`date +%Y%m%d%H%M%S`，单调）。
- `src/services/online/update.js`：检查（启动后/每 6h，不阻塞 boot）→ 下载到 `/userdisk/Favorite/<appid>.<code>.amr.part` → 大小稳定 → `sha256sum` → `unzip -t` + manifest appid/version → 改名。
- 安装：预检 /userdisk ≥300MB、flock 单实例、`Global.keepScreenOn(true)`、暂停播放；写 `/userdisk/Favorite/bpncm_update.sh`；`setsid sh ... &`；脚本 sleep 2 → `miniapp_cli install` → 轮询注册表确认 appid 版本/槽位变化 → 写结果 → `miniapp_cli start <appid>`；应用随后 `$falcon.closeApp()`。失败脚本启动旧 app，保留旧包。
- 设置：`updateAutoCheck`（开）、`updateAutoDownload`（开）、`updateAutoInstall`（关）；更新页显示当前/最新/说明/进度/按钮。
- 不 uninstall；不 `-k`；只接受 `https://api.0xabcd.dev/bpncm/...`；文件 ≤10MB；code 必须更大。

## 二、身份与头像

- `src/services/online/identity.js`：`readSN()`（`yd_misc_info_tool` → `system_info.bin` → `sys_config.conf`，不打印）；`loadDevice()`/`register()`/`ensure()`/`updateProfile()`/`unbind()`；Token 原子写 600。
- 首次社交动作自动注册（SN 只这一次上传），toast 说明；`online` 页展示笔友号、昵称、头像来源、隐私开关、解除绑定。
- 网易云登录后 `POST /me/update` 同步 `avatarUrl`、`neteaseUid`、`avatarSource=netease`；头像 URL 服务端只存不抓取；失败回落昵称首字圆形头像。
- 关闭在线服务/解绑：清 token、清 presence，服务端吊销。

## 三、在线状态

- `src/services/online/presence.js`：App 前台每 45s `POST /presence`；歌曲变化/播放暂停立即上报；`App.onHide` 尽力发一次 `online:false`；`App.onShow` 立即恢复。
- 首页“我的好友”卡：`GET /summary` 的 `onlineFriends`；页面 show 时刷新。
- “我的好友”页：每 30s 拉 `GET /friends`；在线好友显示绿点 + “正在听：歌名 - 歌手”；离线显示“N 分钟前”。限制：切后台后 120s 才离线，回前台恢复。

## 四、口味偏好

- `src/services/online/taste.js`：网易云已登录时 `weapiPost('/api/tag/my/preference/get', {})`；取 `data.tagPreferenceVos`；归一化为 `{tags:[{id,name,ratio}]}`；缓存 `$dataDir/online/taste.json`；上传 `POST /taste/update`。
- 触发：登录后、手动“更新口味”、距上次 >7 天；`tasteShare` 关闭时不上传；未登录/空数据时清除上传并回落最近活跃。
- `online` 页展示 top 标签/占比、更新时间、“更新口味”“清除口味”“允许用口味推荐”开关。
- 好友推荐：`GET /users/recommended?mode=taste&scope=all|friends`；行显示共同标签；无口味时显示最近活跃。

## 五、首页卡片

在现有 5 张卡末尾追加两张（横向 scroller 末尾追加是安全的）：

- **歌曲广场**：图标 `messagesq`/`music`；描述“看看笔友在听哪些歌”；点击 `go('feed')`；未加入先 `go('online')`。
- **我的好友**：图标 `users`；描述“X 个在线”（未加入/离线时相应文案）；点击 `go('friends')`。

不新增“一起听”首页卡。

## 六、歌曲广场

- 新页面 `feed`：顶栏 Pivot“所有人 / 仅好友”（复用 `playlists.vue` 的 pivot 样式/结构）；列表分页 20。
- “所有人”：公开分享；“仅好友”：好友分享（含仅好友）+ 自己。
- 分享卡：作者头像/昵称/时间；歌曲封面/歌名/歌手；可选文字；点歌曲进 `songinfo`，点头像进 `friend`。
- 左栏：返回 + 刷新；空态提示；未加入在线服务时提示加入。
- v1 不做点赞/评论；v1.1 再加。

## 七、分享窗口

- 新页面 `share`（独立窗口，带 `page-shell`），从歌曲详情“更多”→“分享”进入，参数为歌曲对象。
- 顶部 Pivot：“分享到广场 / 私信好友”。
- 分享到广场：歌曲摘要；可见性切换“所有人可见 / 仅好友可见”，初值来自设置 `onlineShareVisibility`（默认 `public`）；可选文字；发布 → `POST /posts` → toast/返回；可在分享窗口单条覆盖。
- 私信好友：好友列表（在线点/名称/正在听）；选择一位；可选文字；发送 → `POST /messages/send` → toast/返回。
- 未注册时先加入在线服务；发送失败保留输入并提示。

## 八、私信

- 新页面 `messages`：收到的歌曲私信列表（发送者头像/昵称、歌曲、时间、未读点）；点开标记已读并进 `songinfo`。
- 入口：`friends` 页“私信”行（未读数）；首页“我的好友”卡仍只显示在线数，不混入私信数。
- v1 只做歌曲私信 + 可选短文本，不做聊天会话/图片。

## 九、我的好友

- 新页面 `friends`：顶栏 Pivot“好友 / 推荐”。
  - 好友：好友列表（在线点、正在听、最近活跃）、收到的请求（接受/拒绝）、我发出的请求、删除好友（二次确认）；顶部“私信”行（未读数）与“一起听邀请”横幅。
  - 推荐：口味匹配列表（共同标签/共同歌手、相似度），范围切换“所有笔友 / 好友的好友”；无口味时显示最近活跃；加好友/等待验证。
  - 左栏“搜索”：系统输入法输入笔友号/昵称；结果列表。
- `friend` 页：头像/昵称/笔友号/在线状态/正在听/共同好友；加好友/等待验证/已是好友；删除好友二次确认。

## 十、一起听

- 入口：歌曲详情“更多”→“一起听”→`together` 页（选择好友）。无首页卡。
- 房主：`together` 页显示好友列表（仅好友）；选择 1–3 位 → 创建房间并发送邀请；随后同一页显示房间状态/成员/当前歌曲/“结束房间”/“打开播放页”。
- 受邀者：`friends` 页“一起听邀请”横幅 → `together` 页接受/拒绝；接受即加入。
- 播放控制：房主在播放页操作，`together.js` 自动同步；客人 1.5s 拉取并校正；前后台切换重同步。
- 限制：仅前台；无聊天；最多 4 人；房主离开即结束；客人需能播放该歌曲。

## 十一、设置/在线服务页

- 设置页新增独立 `cue-row`“在线服务”→ `go('online')`；不要写成 `{key:...}` 对象，避免触发 `theme_verify` 的 GROUPS 检查。
- `online` 页：
  - 身份：头像（网易云）、昵称、笔友号、加入/解绑。
  - 口味：top 标签/占比、更新时间、“更新口味”“清除口味”“允许用口味推荐”。
  - 隐私：“允许其他笔友找到我”（discoverable）、“向好友展示正在听”（showListening）。
  - 分享：“分享到广场默认可见性：所有人 / 仅好友”（默认所有人）。
  - 入口：“私信”“检查更新”。
- 分享默认可见性存本地 config；服务端 `POST /posts` 接收单条 visibility。
