# 手势与交互语义

## 一、歌曲行

| 手势 | 语义 |
|---|---|
| 点行 | 播放 |
| 长按行 | 进歌曲详情页（`songinfo`） |
| 删除 | 一律走「多选态 → 删除键」 |

`list` / `album` / `artist` / `downloads` 四个列表页共用 `SongRow`：

- `SongRow` 根节点挂 `@longpress="onHold"`，抛**自定义事件名 `hold`**，避开 `tap` / `longpress` / `swipe` 等手势名，否则预编译器会再挂一条原生手势通道。
- 页面监听 `@hold="onHold(i)"`，命中后 `go('songinfo', {id})`。
- **多选态忽略长按**：多选时点行是勾选，跳走会打断选择。

### 长按余波防御

设备端 native 实现会在长按之后又发一次 click，形成「开详情页 + 顺手起播/勾选」双动作。修法：

```js
const HOLD_SWALLOW_MS = 3000
onHold()   { this._holdAt = Date.now(); /* ... */ }
onClick()  { if (Date.now() - (this._holdAt || 0) < HOLD_SWALLOW_MS) return; /* ... */ }
```

同页多个可长按控件共用一个时间戳字段时，注意各自命名，避免互相吞点击。

## 二、本地下载

- 总览页（`downloads`）只做导航：横向卡片流 歌单 / 歌手 / 专辑；点卡进对应列表。
- 曲目列表（`dltracks`，四种 kind）：
  - 点行播放；长按进 `songinfo`；多选态忽略长按。
  - 多选 → 删除是删歌的唯一通路（两次点按确认）；遗留页多选另有「保留为单曲」。
  - 歌单内视图有「拉取 / 同步」状态卡片；A（远端有、本地没下）灰字 + 绿 A，D（本地有、远端已移除）仅歌名白色删除线、其余列保持原样式 + 红 D；A/D 标记列常驻占位，不挤动左侧列。
- 删歌只剩「多选 → 删除键」一条通路，没有单首长按删除（与旧本地下载页一致）。
- 歌单详情（从本地下载进入，`plinfo` 参数 `entry:'dl'`）：
  - 左栏底键 = **移除本地索引**（索引切换，只删记录、文件保留）。
  - 「更多」面板底部的两项破坏性动作，都是两次点按确认（第一次点按后标签变「再点一次确认」）：
    - **本地删除**：移除本地索引 + 直接删掉「移出后会进遗留歌曲」的文件（不留孤儿；
      仍被其它索引歌单引用、或用户单曲归属的文件保留）。
    - **删除**：本地删除 + 删远端歌单（`/api/playlist/remove`，仅自己创建，不可逆）。
  - 本地删除成功后停留在本页（索引状态变未索引）；删除成功后关掉下面的曲目列表页并退页。
- 行组件统一用 `SongRow`；歌单内视图通过 `flag` 属性显示 A/D，通过 `tone`/`flag` 推导文字色。

## 三、播放队列来源 `queueSrc`

`queueSrc` 标记「本队列是否从本地下载页进入」，用于删歌/清空后同步收缩队列。

- `player.js`：模块级 `queueSrc`，由 `player.playList(songs, i, src)` 第三参写入（其它页面不传 = `''`）。
- 进快照（`snapshotRecord` 的 `rec.src`），`clearPlayback` 清零，`loadLastState` 从 `s.src` 恢复（老快照无此字段 = `''`）。
- `session.js`：`load()` 返回带 `src` 字段。
- `dltracks.vue`：播放时 `playList(songs, i, 'downloads')` 标记来源（点行起播与「播放全部」都传）；
  删除选中项后，若 `player.state().queueSrc === 'downloads'`，调 `player.removeFromQueue(被删 ids)`。
- `plinfo.vue`（`entry:'dl'` 的本地语境）：面板里的删除/本地删除删掉曲目后，同样按 `queueSrc === 'downloads'` 收缩队列。
- `storage.vue`：清空已下载后，若 `queueSrc === 'downloads'`，清空队列。
- **混合队列不动**：`queueSrc !== 'downloads'` 时不碰队列。

## 四、验证编译产物

改动是否真的进包，以 `.falcon_/*.js.bin` 反汇编为准（`.falcon_` 里没有 `.js`）：

```bash
# 在项目根执行；qjs 工具在工作区 tools/（不在本仓库内）
../../tools/qjs/tool2.exe disasm .falcon_/downloads.js.bin | grep songinfo
```

平时构建通过即视为改动进包；只有怀疑打包问题或核对文案残留时才需要反汇编。
