# 在线服务：部署与验收

> 状态：计划（待实施）。服务端设计见 [在线服务-服务端设计.md](在线服务-服务端设计.md)，客户端设计见 [在线服务-客户端与页面.md](在线服务-客户端与页面.md)。

## 一、部署步骤

> 先建独立工作树：`git worktree add .agents/worktrees/feat/online-service -b feat/online-service main`（规则见 [`../AGENTS.md`](../AGENTS.md)「分支与工作树」）。写 `docs/**`、`AGENTS.md`、`README.md` 前按工作区规则重读 [`../../../DOCS_SPEC.md`](../../../DOCS_SPEC.md)（10 分钟有效）。

1. **服务端代码**：上传 `server/` 到 `/opt/apps/bpncm`（排除 `.env`/`data`/`venv`）；`python3 -m venv venv`；`pip install -r requirements.txt`（PyPI 已验证 200）。
2. **证书**：加 `api.0xabcd.dev` 的 :80 ACME server block → reload；`/root/.acme.sh/acme.sh --issue -d api.0xabcd.dev --webroot /var/www/html --keylength ec-256 --staging` 验证后正式签发；`--install-cert --ecc` 到 `/etc/nginx/ssl/api.0xabcd.dev.{crt,key}` + reload。
3. **nginx vhost**：`/etc/nginx/sites-available/api.0xabcd.dev`，symlink 命名 `zz-api.0xabcd.dev`（排 smart/sms 之后，避免改变默认 vhost）；`/bpncm/releases/` 静态、`/bpncm/` 反代 127.0.0.1:5080；`limit_req_zone` 放 `conf.d/bpncm-ratelimit.conf`；`nginx -t && systemctl reload nginx`；验证 `server.0xabcd.dev`/IP 默认站不变。
4. **systemd/DB**：建 `bpncm` 用户/目录；`.env` 写 `SN_PEPPER`（随机 32 字节）；`bpncm.service`；`init-db`；`release add` 首个 .amr；`/var/www/bpncm/releases` 允许 www-data 读。
5. **备份/日志**：每日 03:15 cron `.backup` + `.env` + zstd；`journalctl -u bpncm`；笔端无 `-k` 验证 `/health`。
6. **笔端**：`bash scripts/build.sh` + `bash scripts/install.sh`；先正式版验证更新检查/下载，再探针 appid 验证 install/重启。
7. **注意**：`sms.0xabcd.dev` 证书约 2026-11-10 01:31 CST 用 alpn 续期会短暂 stop nginx；避开或续期后确认恢复。不做 DNS/防火墙改动。

## 二、测试与验收

### 1. 服务端

- pytest（临时 SQLite）：注册/Token；好友请求/反向接受/删除；presence 在线/过期/隐藏正在听；feed 的 public/friends 可见性；分享/删除；私信好友校验/未读；口味上传/相似度/回落/清除；房间邀请（非好友拒绝）/接受/过期/房主写/客人禁写/seq 冲突/结束/清理；release code 比较；限流/超大 body/SQL 注入。
- 部署后：`/health`；笔端无 `-k`；`http://` 301；`/bpncm/releases/...` 206 Range；`server.0xabcd.dev` 默认站不变；重启后健康；备份恢复演练。

### 2. 客户端静态/构建

- `python scripts/theme_verify.py`、`python scripts/gen_tokens.py`、`python scripts/gen_icons.py --no-fetch --check`、`bash scripts/build.sh`（便携 Node 18）。
- 截图核对首页两张新卡、feed、share、messages、friends、together、online；单类名样式、TOK 颜色、≤50 行/批。

### 3. 更新

- 探针 appid vA→vB，不 uninstall；断言注册表槽位翻转、旧槽目录消失、`data/` marker 仍在、启动后构建号 = vB；再 vC 验证交替；损坏包 sha256 失败不安装；测试 `global.restartMiniapp()`；失败保留旧 .amr 可回滚。
- 正式 appid 一次真实更新，确认登录态/下载/历史不丢；更新只能亮屏前台发起。

### 4. 社交/口味/一起听

- 两个测试用户（随机 SN）验证：分享到广场（所有人/仅好友）、广场 pivot 两种视图、默认可见性设置、私信分享与未读；好友在线/正在听/隐私关闭；口味上传后推荐排序与共同标签；清除口味回落活跃。
- 网易云登录账号验证 `weapiPost('/api/tag/my/preference/get', {})` 返回 tag/ratio 并上传；未登录时为空且回落。
- 头像：登录网易云后 feed/好友/私信显示其头像；失效回落生成头像。
- 一起听：房主从歌曲详情更多进入→选好友→邀请；好友接受→房主播放/暂停/切歌/seek，客人漂移 ≤1.2s；非好友邀请被拒；邀请过期；房主离开结束；前后台恢复。
- 断网/服务端停机：应用启动、首页、更新检查不阻塞/不崩溃；恢复后刷新。

### 5. 验收标准

- P0：证书有效；更新检查/下载/安装/重启可用；正式版数据零丢失；失败可回滚；无 `-k`。
- P1：分享/广场 pivot/私信/好友在线/正在听/口味上传与推荐/首页两卡；SN/Token/Cookie 不出现在服务端日志；不存网易云 Cookie。
- P2：仅好友邀请一起听；房间状态同步；邀请过期/非好友拒绝；前后台恢复。
- 全部：`theme_verify`/`gen_tokens`/`gen_icons --check`/构建通过；文档与实现一致；服务端备份/健康可用。

## 四、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 证书/SAN | 全部在线功能不可用 | acme.sh webroot + staging；笔端无 `-k` 验证；证书路径固定 |
| 自更新装坏 | 应用无法启动 | 不 uninstall；data 不动；保留 last-known-good .amr；探针先验证；失败脚本启动旧版 |
| PMS 槽位/重启行为不符 | 更新失败 | probe 断言 a/b 翻转、data 保留、start 生效；失败退回「只下载 + PC 安装」 |
| 服务端被攻破 → 恶意 .amr | root 代码执行 | HTTPS + SHA-256 + appid/版本；管理仅 SSH；自动安装默认关；v1.1 签名 |
| SN 被读取/伪造 | 账号被顶替 | SN 只做注册标识；Token；限流；公开号不暴露 SN；后续恢复码/拉黑 |
| 公开广场滥用 | 垃圾/骚扰 | 可见性、限流、删除自己的分享；P3 拉黑/举报；广场仅 discoverable |
| 好友在线/正在听隐私 | 用户顾虑 | 仅好友可见；showListening 开关；关闭后清服务端歌曲；文档说明 |
| 后台冻结 | 在线状态过期/一起听漂移 | 心跳 45s + TTL 120s；回前台立即恢复；一起听仅前台，重同步 |
| 口味标签隐私/精度 | 用户顾虑/推荐不准 | 只传标签/占比，不传 Cookie；可关闭/清除；展示共同标签；无数据回落活跃 |
| 网易云接口变动/风控 | 口味获取失败 | 客户端失败保留旧标签/回落活跃；不阻塞主流程 |
| 头像外链失效/防盗链 | 头像不显示 | 服务端只存 URL；客户端失败回落生成头像；不抓取 |
| 一起听版权/VIP | 客人无法播放 | 只同步元数据；失败提示换歌；不代理音频 |
| 私信骚扰 | 打扰 | 仅好友；限流；P3 拉黑/举报 |
| SQLite 单点 | 数据丢失 | WAL、每日 .backup + .env、14 天；规模大迁 Postgres |
| CGNAT 限流 | 误伤 | 按 Token 为主、IP 仅注册/邀请；放宽 burst |
| sms 证书续期停 nginx | 短暂 502 | 避开窗口；后续改 webroot（单独运维项） |
| 主工作树脏/文档门禁 | 合并/写文档失败 | 独立 worktree；写 docs 前重读 DOCS_SPEC；合回前清理 main |
