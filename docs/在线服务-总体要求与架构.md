# 在线服务：总体要求与架构

> 状态：计划（待实施）。目标环境：`https://api.0xabcd.dev/bpncm`，目标机器 `ssh <服务器别名>`。
> 本组文档写当前要求、设计决策与实施顺序；实施后的行为以代码与 `server/README.md` 为准。
>
> 分篇：[服务端设计](在线服务-服务端设计.md)、[客户端与页面](在线服务-客户端与页面.md)、[部署与验收](在线服务-部署与验收.md)。

## 一、结论

服务端与自动更新可先上线；社交部分按“歌曲广场 + 好友在线 + 分享 + 一起听”落地。口味偏好直接由客户端调用网易云官方接口获取，只把标签/占比上传到自建服务端，不把网易云账号或 Cookie 交给服务器。

| 模块 | 结论 | 关键依据 |
|---|---|---|
| 服务端/部署 | 可行，改动小 | DNS 已指向本机；Debian 13、nginx、Python 3.13、sqlite3 就绪；80 可 ACME；acme.sh 已装；无主机防火墙 |
| 自动更新 | 可行，优先做 | 同固件 Loli 已实证 `miniapp_cli install`；PMS 用 a/b 槽，`data/` 共享，更新不丢数据；.amr 约 424KB |
| 身份 | 可行 | SN 可读；SN 只做注册标识，服务端发 Token；公开笔友号；头像用网易云公开头像 |
| 口味偏好 | 可行，已实测 | `POST /weapi/tag/my/preference/get` 返回 `tagPreferenceVos`（tagName/ratio）；未登录返回空数组 |
| 歌曲广场/分享 | 可行 | 现有页面/列表/输入法可复用；服务端 SQLite 足够 |
| 好友在线/正在听 | 可行，有前台限制 | 心跳 + TTL；切后台 JS 冻结后在线状态会过期 |
| 一起听 | 可行，仅好友邀请 | 自建房间状态同步；参考文档没有稳定的“一起听”接口；两端各自播放 |

## 二、当前要求（产品口径）

1. **口味偏好**：直接用网易云音乐接口获取口味偏好，上传到自建服务器；不把网易云账号/Cookie 交给服务器。
2. **好友状态**：允许查看好友的在线状态和当前正在听的歌曲。
3. **分享**：歌曲详情“更多”里的“推荐给笔上好友”改为“分享”，在独立的分享窗口操作；可分享到广场，或私信分享给某个好友。
4. **广场默认公开**：分享到广场的音乐默认向所有人公开，可在设置中切换默认可见性。
5. **首页卡片**：
   - “歌曲广场”（描述“看看笔友在听哪些歌”）
   - “我的好友”（描述“X 个在线”）
   - “一起听”不作为首页卡片
6. **歌曲广场视图**：可按“所有人 / 仅好友”查看，使用类似歌单列表的顶栏 Pivot。
7. **一起听入口**：位于歌曲详情页“更多”，点击后打开页面选择好友。
8. **自动更新**：保留首版目标（检查、下载、安装/重启），不因社交功能扩展而取消。

## 三、现有依据

### 1. 目标机

- Debian 13，2 vCPU / 1.9G 内存 / 31G 空闲；nginx 1.26.3；Python 3.13.5；sqlite3 3.46.1；5080–5099 空闲；无主机防火墙。
- `api.0xabcd.dev` 的 A 记录已指向 `<服务器 IP>`（Cloudflare DNS-only）；80 端口可达，默认 :80 vhost 已为任意 Host 提供 `/.well-known/acme-challenge/`；acme.sh v3.1.5 已装。
- 当前 `https://api.0xabcd.dev/` 落到 `smart.zznfzx.com` 默认站，证书 SAN 不匹配；`/bpncm` 是 smart 的 404。唯一硬阻塞是证书 + vhost。
- 现有 `sms-code-sync.service` 提供可复用的 venv/gunicorn/systemd/备份模式。

### 2. 笔端

- SN：`yd_misc_info_tool -r YD_LINUX_SN_ID` → `YD_LINUX_SN_ID: <设备 SN>`；`/userdata/cfg/system_info.bin`（644）、`sys_config.conf`（`dev_sn=`）一致；`/etc/machine-id` 全镜像共享，不可用。
- 应用以 root 运行；`process.exec('/bin/sh',['-c',...])` 可用；当前代码 `pkg/8000200708310039/b/`，数据 `pkg/.../data/`（约 404MB）；PMS 注册表 `/userdata/miniapp/data/mini_app/pkg/packages.json`。
- PMS a/b 双槽，`data/` 在槽外；首次装 `a/`，覆盖装另一槽并翻转 `b`，旧槽删除，data 不动；只校验 unzip/manifest/appid/version/逐文件 md5，无签名链。
- Loli 实证：下载到 `/userdisk/Favorite/` → `miniapp_cli install` → 轮询注册表 → 重启；不 uninstall。`miniapp_cli` 是 `/var/run/miniapp-dbg.socket` 客户端，root 可在应用运行中调用。
- 重启：`$falcon.closeApp()`；`global` 有 `restartMiniapp()`（待 probe）；兜底 detached `miniapp_cli start`。`setsid`/`nohup`/`flock`/`unzip`/`sha256sum` 可用。
- 网络：curl 7.77 + OpenSSL 1.1.1k，CA 正常；设备 NTP 时钟准确；当前 `api.0xabcd.dev` 仅证书 SAN 不匹配。
- 后台：切后台 JS 冻结；SoundPlayer 独立进程继续放音。在线状态/一起听只能前台维持；回前台重同步。

### 3. 口味接口实测

- NeteaseCloudMusicApi 的 `/style/preference` 是封装名，实际请求为 weapi：`/api/tag/my/preference/get`。
- 用笔端现有登录 Cookie + 项目自带 `src/services/ncm/crypto.js` 实测：`POST https://music.163.com/weapi/tag/my/preference/get` → HTTP 200。
- 返回结构：`data.tagPreferenceVos` 为 `[{tagId, tagName, ratio}]`；实测样本：二次元 57%、流行 34%、原声带 4%、摇滚 3%、另类/独立 2%。
- 未登录时返回 `{"data":{"tagPreferenceVos":[],"tags":[]},"code":200}`，不是报错。
- 结论：客户端用现有 `weapiPost('/api/tag/my/preference/get', {})` 即可拿到；只上传 `tagId/tagName/ratio`，不传 Cookie。

## 四、总体架构

```
笔端（QuickJS + Vue2）
  ├─ src/services/online/  identity / presence / feed / share / taste / together / update
  ├─ 现有 player、download、nav、PageShell、ncm（weapi/cookie）
  └─ process.exec / miniapp_cli（root）
        │ HTTPS（校验证书）
        ▼
https://api.0xabcd.dev/bpncm
  ├─ nginx 443 ── /bpncm/api/  → 127.0.0.1:5080（gunicorn + Flask）
  │             └ /bpncm/releases/ → /var/www/bpncm/releases（静态 .amr）
  └─ SQLite /opt/apps/bpncm/data/bpncm.sqlite3
```

- 不代理音频；一起听只同步 `song/position/playing`；两端各自向网易云取直链。
- 不代理网易云账号；口味只上传标签；服务端不存 NetEase Cookie。
- 路径保留 `/bpncm` 前缀；Flask 路由 `/bpncm/api/v1/...`。
