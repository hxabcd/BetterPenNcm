### 1. 当前落地的菜单

**歌曲详情 `songinfo`**（对齐「歌曲详情」）：返回 / 更多（`ellipsis` → 收藏到歌单、下一首播放）/ 播放 / 下载。

**歌单详情 `plinfo`**（对齐「歌单详情-可写」）：两种入口，菜单不同。

A. 普通入口（在线曲目列表页点顶栏）：

- 返回
- 更多（`ellipsis`）→ 面板：下载全部 / 添加到本地索引（已索引时变「移出本地索引」）/ 重命名（仅自己创建的）
- 播放全部
- 删除（仅自己创建的；两次点按确认）/ 订阅歌单第 4 键为收藏（星标，已收藏时高亮）

B. 本地下载入口（`dltracks` 顶栏点进来，参数 `entry:'dl'`；此时歌单已在本地索引里）：

- 返回
- 更多 → 面板：下载全部 / 重命名（自己创建）/ 收藏切换（订阅）/ **本地删除** / **删除**
- 播放全部
- **移除本地索引**（底键，索引切换：已索引 = `database-minus`，未索引 = `database-plus`）
- 面板里的两项破坏性动作都是两次点按确认（第一次点按后标签变「再点一次确认」）：
  - **本地删除** = 移除本地索引 + 直接删掉「移出后会进遗留歌曲」的文件（不留孤儿；
    仍被其它索引歌单引用、或用户单曲归属的文件保留）。
  - **删除** = 本地删除 + 调 `/api/playlist/remove` 删远端歌单（仅自己创建；不可逆）。

与 CSV 的差异：

- CSV 的「排序」在歌单详情页没有列表可排；排序属于曲目列表页。故「更多」里不放排序。
- 「下载全部」与「添加到本地索引」是两项独立动作：前者下载音频，后者只建索引。
- 「我喜欢」（specialType=5）只给 返回 / 更多 / 播放全部，不给改名/删除。
- 本地下载入口把「删除」从底键降级到面板、把本地索引切换提为底键：本地语境优先本地动作，
  云端删除是低频且不可逆的操作，放到面板底部。

**本地下载曲目列表 `dltracks`**：

- 常态：返回 / 播放全部 / 多选
- 多选：关闭 / 下一首播放 / 收藏到歌单（遗留页换成「保留为单曲」）/ 删除
- 歌单内视图额外有状态卡片（拉取 / 同步），不占左栏槽位。

**本地下载总览 / 歌单索引 / 歌手 / 专辑**：

- 总览：返回 / 下载队列
- 歌单索引：返回
- 歌手 / 专辑：返回 / 排序（浮层面板）
- 排序面板用统一组件 `ContextSheet`：贴左栏下部向上生长，遮罩只盖内容区、不盖左栏；
  结构、几何与曲目列表页的排序浮窗一致。

### 2. 与 CSV 的剩余差异

CSV 的左栏目标已全部落地，剩余差异只有语义层的取舍：

- 队列多选的「删除」按队列语义落成「移除」（只移出队列、不删文件）；CSV 未区分这两种动作。
- 「下一首播放」由 `player.insertNext`（插到当前曲之后）支撑，队列为空时改为直接起播。

后续新增动作时，按本文的槽位顺序改各页 `rail()`；槽位上限仍是
「返回 + 3 个上下文键」（`NavRail` 的 100vh 几何）。

### 3. 主题色与深色变体

- **主题色图标**（`ACCENT_ICONS`，每个预设色一份 PNG，用 `aIcon(key, accent.key)` 取）：
  `liked`、`pl`、`dl`、`hist`、`rec`、`dlpl`、`dlar`、`dlal`。
- **深色变体**（`DARK_ICONS`，落在实心主题色上的图标）：`check`、`download`、`play`、`pause`、`trash`，
  用 `fgIcon(key, accent)` 取。
- 新增图标默认纯白；只有 `note`、`chevright` 走 `COLORS` 着色（原因见 [`图标系统.md`](图标系统.md)）。
- 命名按**用途**不按字形：`dbplus` / `dbminus` 成对；`dlpl` / `dlar` / `dlal` 是本地下载三卡；
  `music` 与 `note` 同字形但用途不同（前者是入口图标，后者是无封面占位灰图）。

当前生成器共 **67 个 key / 120 个 PNG**（`python scripts/gen_icons.py --no-fetch --check`）。
