# 平台约束与自检

本文只收「构建期不报错、运行时才炸」的平台坑，以及对应的自动检查。改主题、页面结构、模板绑定或视觉常量前先读。

## 一、最阴的一类 bug：用了但没 import

JS 引用未导入的标识符时，构建期不报错（编译器按全局查找处理），照常出包；如果出错点在 `data()` / render 里，整个页面组件创建失败，表现为整页黑屏。

`scripts/theme_verify.py` 第二道检查：扫描下列 16 个符号，在 `<script>` 段里用了却没出现在 import 里就报错（先剥掉注释与模板）：

```
currentBg  currentAccent  currentAccentKey  bindTheme  unbindTheme
setBg  setAccent  accentMixin  aIcon  fgIcon  ACCENTS  PRESETS  currentKey  ICON
railBack  railBtn
```

## 二、平台渲染硬约束

样式、动画/帧调度、响应式、组件结构的平台硬约束（单类名选择器、`<image>` 不能染色、`:style` 数组静默忽略、rAF 不可用、`transition` 只在 class 内插值、`transitionend` 不触发、`font-size`/`color` 无 CSS 平滑路径、data 字段必须预声明、methods 与 mixin computed 同名静默丢弃等）**已并入 [`docs/小程序平台行为速查.md`](../../../docs/小程序平台行为速查.md)**，本文不重复；此处只保留与本项目自检直接相关的一条：

- **`<image>` 不能染色**：颜色必须生成进 PNG 文件本身（`scripts/gen_icons.py` 的前提）。

含 slot 组件的模板结构约定（保持恒定）**不在**上述硬约束之列：它只有一次事故记录、X3S 上按简化形态未复现，依据与复验方法见 [`待验证-slot补插错位.md`](待验证-slot补插错位.md)。

改动涉及的渲染表现问题，先查速查文档再上设备验证。

## 三、注册与导航

- 新页面必须在 `src/app.json` 的 `pages` 注册——不注册构建不报错，点进去断链。
- **导航统一走 `src/core/infra/nav.js`**（逻辑页 → 实例槽位）。页面代码只写**逻辑页名**（app.json 里该 .vue 的同名基础 key）：`go('list', params)`、`paramsFor(...)`、`this.$page.finish()`；**不直接 `$falcon.navTo`、不写槽位 key（`list2` 等）、不传变量页名**。
- app.json 里同一个 .vue 可以注册多个 key：基础 key = 逻辑页名，其余 = **实例槽位别名**（`list2`/`songinfo2`/`album2`…）。导航层 `go()` 每次挑一个当前不在栈里的槽位 key 再 navTo，得到标准 push/pop 语义；每个别名 key 各编译一份 `.falcon_/<key>.js.bin`，但只是几百字节的 re-export。
- 槽位表在 `core/infra/nav.js` 的 `PAGES` 里维护：`slots[0]` 必须与逻辑页同名；槽位数按「可能同时存活的视图层数」给（热点页 6 / playlists 4 / 部分 2 / 叶子 1）。`player` / `index` 标 `reuse: true`（全局目的地页，已在栈中时回退到它）；连点由 `go()` 合并（500ms 同逻辑页同参数），槽位耗尽才走 `degrade`（复用最上层同类实例，异常路径）。
- 平台 `navTo` 对已在栈里的同名页是「弹掉上层 + 复用旧实例 + 只补 `onNewOptions`」，不重挂载；旧实现里的 `onPageParams`（复用页接新参数）与手写别名 key 均已废弃，不要再引入。
- 新增/调整页面层级的完整步骤见 [`页面导航.md`](页面导航.md)；`theme_verify.py` 第六道硬校验逻辑页 / 槽位 / app.json / 所有 `go()` 调用点。

## 四、构建与打包实证

换文件位置、加页面、改 import 风格前先看这几条（证据在构建器源码里；下文 `src/…` 指 `tools/aiot-build/node_modules/aiot-vue-cli/src/`）：

1. **页面装载按 key，不按路径**：运行时 `$falcon.__loadModuleDefault(fileName)` 直接 `import('./' + fileName + '.js')`，`fileName` = app.json 的页面 key（`rollup-plugins/app.js:55-61`）；构建入口同样按 key 取名（`libs/appinfo.js:241-257`：`input[page] = <app.json 中该 key 的 value>`）。所以挪 `.vue` 只要 key 不变就不影响装载；「key = 目录名 = 文件名」是项目侧约定，靠 `theme_verify.py` 的 `src/pages/*/*.vue` glob 与第六道导航校验维持。
2. **SFC 不能 re-export**：`.vue` 没有转发导出，移动或改名组件/页面必须同步改所有 import 它的文件，做不了「过渡期双路径」。
3. **chunk 按引用图切分**：入口 chunk 名 = app.json key，共享块由 rollup 按引用图自动切（`libs/rollup.config.js:27-30` 的 `getManualChunks` 返回空实现）；实测产物 `.falcon_/` 下 89 个 `.js.bin`，含 `boot-<hash>.js.bin` 这类 hash 命名。挪文件只改 hash 与 scopeId / `__file`，不动 chunk 成员关系。
4. **`@` → `src` 别名内建**：`libs/rollup.config.js:79` 固定注册 `{ find: '@', replacement: <appRoot>/src }`，自定义别名走 app.json 的 `options.alias`（`:42-47`）；`~/` 无证据。本项目全工程写相对 import、0 处 `@/` —— `../` 的层数就是依赖跨度的视觉信号。
5. **manifest 逐文件 md5**：打包末尾对 dist 每个文件记 `size` + `md5` 写进 `manifest.json`（`steps/manifest.js:57-64`），与文件路径无关。

## 五、改完必跑的三项自检

```bash
python scripts/theme_verify.py
python scripts/gen_tokens.py
python scripts/gen_icons.py --no-fetch --check
```

三项都应以退出码 0 结束。各自判据：

### `theme_verify.py`（八道）

1. **片段检查**：`CHECKS` 表列出每个文件必须出现的实现片段；删/并文件后要同步这张表（否则第一道直接报文件不存在）。
2. **缺 import**：上面 16 个符号用了但没 import。
3. **mixin 契约**：页面接了 `multiSelectMixin` 就必须定义 `multiList()`；漏了不会报错，但「全选」永远按空范围算。
4. **模板裸绑定（硬失败）**：`src/pages` 与 `src/components` 下所有模板的裸标识符，必须由 props / computed / data 提供；只由 methods 提供即失败。判据按缩进把 mixin 与页面成员的 computed / methods / data / props 归组。同一道还查**页面 methods 与 mixin computed 同名**（页面那份被 Vue 静默丢弃，见「组件结构」末条）——判据只能看页面自己的分组，不能与 mixin 取并集。
5. **token 值字面量（硬失败）**：`src/{pages,components,styles}` 下不允许出现 token 的颜色值字面量；白名单是 `src/ui/tokens.js`、`src/styles/common.less`（整文件）与 `scripts/gen_tokens.py`——`common.less` 的生成段之外目前也整文件跳过。只巡颜色不巡尺寸，避免与普通间距撞车。
6. **导航路由表（硬失败）**：`core/infra/nav.js` 的 `PAGES`、`app.json` 的页面 key、各页 `go()` 调用点三者一致——逻辑页必须有同名基础 key、槽位 key 必须注册且指向同一 .vue、app.json 不允许孤儿页、页面文件都要有注册；`go()` 第一参必须是已登记逻辑页的字符串字面量；源码里不允许出现旧别名 key（`songinfonested`/`artistlist`/`playlistpick`）、`onPageParams`、或 `$falcon.navTo` 直连（nav.js 除外）；`go('index')` 放行但视为违规（根页不是导航目标），settings 二级菜单表与 `openGroup` 字面量分支必须一一对应。
7. **分层方向（硬失败）**：按目录轴校验 import 边（R1-R6，规则与豁免清单见 `scripts/theme_verify.py` 第七道）。
8. **相对导入存在性（硬失败）**：`src/**/*.{js,vue}` 的所有相对 import 目标必须存在（补 `.js/.vue/.json/.less` 等常见扩展名）。S1/S3 目录重构曾有三处路径多退一级，aiot-cli 只给警告、运行到页面 import 才黑屏——2026-11-22 X3S 首跑即被此挡住。

### `gen_tokens.py`

校验 `src/styles/common.less` 的 `@tokens:begin~end` 段与 `src/ui/tokens.js` 的值表一致。改视觉常量：改 `tokens.js` → `python scripts/gen_tokens.py --write` → 再跑三项自检。

### `gen_icons.py --check`

校验 PNG 数量与 `src/assets/icons.js` 注册表是否与生成器逐字节一致。当前为 67 个 key / 121 个 PNG；`icons.js` 是纯生成物，手改会被拦下，用 `--emit-js` 重新生成。

## 六、平台坑清单（真机实测）

本项目自己的踩坑记录（§二 引的跨应用速查是 S7 通识，本节含 X3S 差异与项目侧后果）。新坑加到末尾，一条一句：现象 → 做法。

1. **样式只认单类名选择器**：复合选择器被丢弃 → 状态样式走内联 `:style` 或独立完整类名
2. **嵌套 `<text>` 富文本会让渲染器崩溃** → 用并排的独立 text
3. **`<image>` 必须 `file://` 前缀**（裸路径黑块）；http 直链也可用；不能用 `<image>` 染色
4. **页面 data 动态 key + `$set` 不触发重渲染** → 增量更新走组件自己的普通属性
5. **一次渲染 ≤50 行** → 长列表按 `ui/paging.js` 口径分片
6. **页面会挂两遍** → `mounted` 初始化必须幂等
7. `$dataDir` 末尾自带 `/`；**`fs` 无写入接口**（`writeFile`/`rename`/`unlink` 都是 `undefined`），但 `mkdir`/`rm` 是递归的 → 建删目录不必走 shell；结构化数据进 SQLite，二进制走 `http.download({outPath})`
8. **别名拆分只用 `/` `;` `；`**（逗号顿号都不行）
9. **`border-radius: 50%` 不生效** → 圆形写等价 vh 值
10. **固定宽标签容器按最长标签算宽度**：装不下会折行，把整块撑高并溢出
11. **浮层穿透**：遮罩挂关闭、内层面板挂空方法（平台无 `stopPropagation`）；互斥点击区各自挂 handler、共同父节点不挂
12. **无系统 dblclick**，双击自己用时间戳判定；**长按有原生 `@longpress`**（500ms，触发后不再走 click，但设备端可能补发一次 click → 见 `HOLD_SWALLOW_MS`）
13. **浮层的绝对定位基准是 `.psh-body`**，遮罩只盖内容区、不盖左栏
14. **图标用 data-URI PNG**（`?base64` 导入被内联）；别改 SVG data URI
15. **触摸坐标字段因固件而异**（`core/platform/touch.js` 兜底）；拖动只用两点之差，坐标系无关
16. **`watch` 不去重**：依赖高频 computed 的 watch 会被反复回调 → 带副作用的回调在入口自己判重
17. **绝对定位别用负偏移**（会被当 0 或被父容器裁）→ 父元素放大到最大子元素尺寸 + 子元素零偏移
18. **任何宽度 >100vh 都被静默截到 100vh**（1vh = 2.4px，基准 ≈953px）→ 超限一律写 px 或百分比；改完截图 + 像素扫描
19. **横向 scroller**：卡片必须显式 `width` + `height` 且不写 `flex: none`；竖向各段别贴满可用高度（取整会静默裁 1px）
20. **`flex: 1` 只在父容器高度确定时才有高度**，父高由内容撑出时塌成 0
21. **`<text>` 默认自动折行，`lines` 是「最多几行」**：要读完整就「scroller + 不写 lines」，要截断才写
22. **`miniapp_cli start` 的页名写裸名**（带 flag 会被当页面文件名 → 黑屏）；`injectKey` 不驱动 UI，遥控走 `/tmp/bpncm_cmd.log`（详见 [`调试与设备操作.md`](调试与设备操作.md) §四）
23. **截图用 `miniapp_cli capture`**，熄屏时返回空白帧 → 先点亮屏幕（[`调试与设备操作.md`](调试与设备操作.md) §四）
24. **模板 `:x="x"` 是「取字段」不是调用**（字节码实证 `get_field`）：裸绑定只能来自 props / computed / data，来自 methods 会拿到函数 —— 轻则静默失效，重则整块 UI 消失；`theme_verify.py` 第四道按此硬判
25. **平台 `navTo` 对已在栈里的同名页不新建实例**（弹掉上层 + 复用旧实例 + 只补 `onNewOptions`）→ 页面代码只走导航层（[`页面导航.md`](页面导航.md)）；`theme_verify.py` 第六道硬校验
