# 图标系统与墨迹对齐

图标生产链：Lucide SVG → `scripts/gen_icons.py` 栅格化为 PNG → `src/assets/icons.js` 注册表。平台不能给 `<image>` 染色，颜色必须生成进 PNG。生成/重建需要 ImageMagick 7（`magick`）与 Pillow；只跑 `--check` 也需要 Pillow。

## 一、加一个新图标

| # | 位置 | 要点 |
|---|---|---|
| 1 | `scripts/gen_icons.py` 的 `ICONS` 表加一行 | 主题色图标还要进 `ACCENT_ICONS`；实心底图标进 `DARK_ICONS` |
| 2 | `python scripts/gen_icons.py` → `python scripts/gen_icons.py --emit-js` | 前者生成 PNG，后者重写注册表 |

`src/assets/icons.js` 是**纯生成物**：`--check` 对其逐字节校验，手改会被拦下并提示 `--emit-js` 复原。

**命名约定**：按**用途**命名，不按字形——同一字形可以有多个 key（如白色 `download` 给播放器页，`dl` 是同一字形的另一个 key）。

**加/减主题色**：`src/utils/theme.js` 的 `ACCENTS` 与 `scripts/gen_icons.py` 的 `ACCENTS` 同改，先跑 `python scripts/gen_icons.py`（生成 PNG），再跑 `python scripts/gen_icons.py --emit-js`（重写注册表）。

当前 `ACCENT_ICONS`：`liked`、`pl`、`dl`、`hist`、`rec`、`dlpl`、`dlar`、`dlal`
（前五个是首页/播放页既有锚点，后三个是本地下载总览的歌单/歌手/专辑卡）。

## 二、图标看起来大一圈：墨迹 bbox 不一致

当前 PNG 都是 72px 画布，但显示尺寸随位置不同（首页卡片 23vh、左栏按钮 10vh、播放页控制 20vh 等）。Lucide 各图形在画布里的留白不同，本节 bbox 以首页卡片的 23vh 图标为例：

| 图标 | bbox |
|---|---|
| `pl` | 56 |
| `dl` | 62 |
| `hist` | 62 |
| `rec`（sparkles） | 68 |

`rec` 比 `dl`/`hist` 大 10%、比 `pl` 大 21%，真机量出来是 52px vs 46px。尺寸没写错，是墨迹占比不同。

### 修法：`INK_SCALE`

```python
INK_SCALE = {'rec': 62/68}    # 目标 bbox / 原始 bbox
```

`build_svg` 收 `key` 参数，做绕画布中心的变换：

```svg
<g transform="translate(c c) scale(s) translate(-c -c)">
```

### 两个实现约束

1. **缩放中心是 12，不是 `out_px/2`**：根标签是 `viewBox="0 0 24 24"`，只有 width/height 被改成 72，transform 用的仍是 24 坐标系；写 36 会把图形推出画布。
2. **`<g>` 插在 body 最前、`</g>` 紧贴 `</svg>` 之前**：body 是「根标签之后的全部内容」；插到末尾会得到空组，PNG 不变。

### 验收

```bash
python scripts/gen_icons.py --no-fetch --check
```

当前应报 67 个 key / 120 个 PNG，且 `icons.js` 与生成器逐字节一致。`rec` 的 bbox 应为 `(5,5,67,67)`，覆盖率约 28.2%（`hist` 约 28.3%）。

## 三、墨迹对齐与内边距

Lucide 图形横竖内缩比例相同，所以**内边距相等 = 墨迹到左 = 墨迹到上**。但盒子大小会改变内缩量：改图标尺寸时内边距要跟着重配，不能照抄。

量渲染图时别拿「非底色像素」当墨迹：通栏 1px 分隔线的 x 恒等于视口右沿，会污染「最右墨迹」判定；要按颜色挑目标元素（如按饱和色找色块）。
