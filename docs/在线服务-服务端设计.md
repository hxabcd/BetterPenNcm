# 在线服务：服务端设计

> 状态：计划（待实施）。接口路径、数据模型与限制是客户端实现的依据；客户端侧调用点见 [在线服务-客户端与页面.md](在线服务-客户端与页面.md)，部署步骤见 [在线服务-部署与验收.md](在线服务-部署与验收.md)。

## 一、栈与目录

- Python 3.13 + Flask 3 + gunicorn + SQLite；复用服务器已有 venv/gunicorn 运维模式。
- 用户 `bpncm`；代码 `/opt/apps/bpncm`；venv；DB `/opt/apps/bpncm/data/bpncm.sqlite3`（WAL）；`.env` 600（`SN_PEPPER`）。
- systemd `bpncm.service`：`gunicorn --bind 127.0.0.1:5080 --workers 2 --threads 8 --timeout 30`；`ProtectSystem=full`、`PrivateTmp=true`、`ReadWritePaths=/opt/apps/bpncm/data`。
- 静态发布 `/var/www/bpncm/releases/<appid>/<code>.amr`，nginx Range/ETag/immutable。

```
server/
  bpncm/  __init__.py config.py db.py auth.py api/{health,device,me,users,friends,feed,presence,messages,taste,rooms,releases}.py manage.py
  tests/  conftest.py test_auth.py test_feed.py test_presence.py test_messages.py test_taste.py test_rooms.py test_releases.py
  deploy/ nginx-api.0xabcd.dev.conf bpncm.service install-server.sh backup.sh deploy-from-pc.sh
  requirements.txt / requirements-dev.txt / README.md
```

## 二、数据模型

| 表 | 关键列 |
|---|---|
| `devices` | id, sn_hash UNIQUE, token_hash, model, fw, app_code, created_at, last_seen_at, revoked_at |
| `users` | id, device_id UNIQUE, public_id UNIQUE, nickname, avatar_url, avatar_source, netease_uid, discoverable, show_listening, taste_share, created_at, last_seen_at |
| `friend_requests` | id, from_user, to_user, status, created_at, responded_at；pending 对唯一 |
| `friendships` | user_lo, user_hi, created_at；主键，lo<hi |
| `presence` | user_id PK, last_seen_at, song_json, playing, updated_at |
| `posts` | id, user_id, song_id, song_json, comment, visibility(public/friends), created_at, deleted_at |
| `direct_messages` | id, from_user, to_user, song_id, song_json, text, created_at, read_at |
| `user_tags` | user_id, tag_id, tag_name, ratio, updated_at；主键 `(user_id,tag_id)` |
| `rooms` | id, host_user, status(active/ended), created_at, last_active_at, ended_at |
| `room_members` | room_id, user_id, role(host/guest), joined_at, last_seen_at |
| `room_state` | room_id PK, seq, song_json, position_ms, playing, updated_at |
| `room_invites` | id, room_id, from_user, to_user, status(pending/accepted/declined/expired), created_at, responded_at |
| `releases` | id, appid, channel, version, code, url, sha256, size, notes, mandatory, active, created_at |
| `rate_events` | ip, action, at（注册/发帖/私信/邀请等限流） |

- 时间戳 Unix ms；WAL、foreign_keys、busy_timeout；所有 SQL 参数化。
- `public_id`：`BP-` + 6 位去混淆字符；昵称可重名；公开号唯一。
- `sn_hash = HMAC-SHA256(SN_PEPPER, sn)`；原 SN 不落库、不写日志；Token 32 字节随机，DB 存 SHA-256。

## 三、API（仅 GET/POST）

Base：`https://api.0xabcd.dev/bpncm/api/v1`；统一响应 `{ok,data,serverTime}` / `{ok:false,error:{code,message},serverTime}`。

| 方法/路径 | 鉴权 | 说明 |
|---|---|---|
| `GET /health` | 无 | DB 检查、版本、时间 |
| `POST /device/register` | 无（限流） | `{sn, model?, fw?, appVersion?, appCode?, nickname?, avatarUrl?, neteaseUid?}` → `{deviceId, token, user}`；同 SN 重注册轮换 Token |
| `GET /me` / `POST /me/update` | Token | 昵称、头像、`discoverable`、`showListening`、`tasteShare` |
| `POST /device/rotate` / `POST /device/unbind` | Token | 轮换/解绑 |
| `GET /summary` | Token | `{friends, onlineFriends, unreadMessages, pendingInvites, activeRoom}` |
| `POST /presence` | Token | `{online, song?:{id,name,artist,playing}}`；心跳/状态更新 |
| `GET /friends` | Token | 好友列表、`online`、`nowPlaying`（仅 show_listening 时）、incoming/outgoing requests |
| `POST /friends/request` / `POST /friends/respond` / `POST /friends/remove` | Token | 请求/接受/删除；反向 pending 自动接受 |
| `GET /users/search?q=` | Token | 公开号精确/昵称模糊；仅 discoverable；limit 20 |
| `GET /users/recommended?mode=taste\|active&scope=all\|friends&limit=20` | Token | 口味匹配优先；返回 `score/matchTags`；无标签回落最近活跃 |
| `GET /users/{id}` | Token | 资料 + isFriend/hasPending/mutualCount |
| `GET /feed?scope=all\|friends&cursor=&limit=20` | Token | 歌曲广场：all=公开分享；friends=好友分享（含仅好友）+ 自己 |
| `POST /posts` | Token | `{song:{id,name,artist,album,cover,durationMs}, visibility:'public'\|'friends', comment?}` |
| `POST /posts/{id}/delete` | Token | 仅作者 |
| `POST /messages/send` | Token | `{toUserId, song, text?}`；仅好友；私信分享 |
| `GET /messages?cursor=` | Token | 收到的私信列表；含发送者/歌曲/未读 |
| `POST /messages/read` | Token | `{ids:[...]}` |
| `POST /taste/update` | Token | `{tags:[{id,name,ratio}]}`；1–10 个；ratio 0–100 |
| `GET /me/taste` / `POST /taste/clear` | Token | 查看/清除口味 |
| `POST /rooms/create` | Token | `{song?}`；创建房间，房主 |
| `POST /rooms/{id}/invite` | Token（房主） | `{userIds:[...]}`；仅好友；最多 4 人 |
| `GET /invites` | Token | 收到的一起听邀请 |
| `POST /invites/{id}/respond` | Token | `{accept}`；接受即加入 |
| `GET /rooms/{id}?sinceSeq=` | Token（成员） | 房间状态/成员；`changed=false` 不返回大对象 |
| `POST /rooms/{id}/state` | Token（房主） | `{seq,song,positionMs,playing}`；seq 冲突 409 |
| `POST /rooms/{id}/heartbeat` / `POST /rooms/{id}/leave` / `POST /rooms/{id}/end` | Token | 心跳/离开/房主结束 |
| `GET /rooms/current` | Token | 恢复当前房间 |
| `GET /releases/latest?appid=&code=&channel=stable` | 无 | 更高 code 才返回更新；否则 `{update:false}` |

限制：body ≤16KB；昵称/歌名/评论 ≤100 字；发帖 ≥20/天/用户；私信 ≥50/天/用户；好友请求 ≥30/天；注册 ≥5/小时/IP；邀请 ≥60/天/用户；presence ≥1/20 秒/用户；搜索 ≥60/分钟/用户。

## 四、身份与安全

- SN 只做注册/找回标识；HMAC 存 hash；Token 鉴权；公开号/昵称/头像对外；SN 永不返回/写日志。
- Token 存 `$dataDir/online/device.json`（600）；401 清 token 重注册一次；换机/重装用 SN 重注册轮换。
- `discoverable=0`：不出现在搜索/推荐/广场；`show_listening=0`：好友只看到在线，不显示正在听；`taste_share=0`：不参与口味推荐，可清除标签。
- 在线服务请求走 `noCookies`，不把网易云 Cookie 发给自建服务；服务端不存网易云登录凭据。
- 更新安全：HTTPS + SHA-256 + size + appid + 版本单调；禁止 `-k`；自动安装默认关。

## 五、在线状态

- 客户端前台心跳 45 秒；歌曲变化/播放暂停时立即上报；`POST /presence` 更新 `presence` 表。
- 服务端 `online = now - last_seen_at < 120s`；`nowPlaying` 仅当好友 `show_listening=1` 且 `playing` 时返回。
- `GET /friends` 返回 `{online, nowPlaying:{id,name,artist}, lastSeenAt}`；`GET /summary` 返回 `onlineFriends`。
- 切后台 JS 冻结 → 心跳停止 → 120 秒后好友看到离线；回前台立即心跳恢复。该限制在 UI/文档中说明。
- 隐私：在线状态对好友可见；正在听可通过设置关闭；关闭后上报 `song=null` 并清除服务端歌曲。

## 六、歌曲广场 / 分享 / 私信

- `posts.visibility` 支持 `public`（所有人）与 `friends`（仅好友）。
- 分享默认可见性由设置决定：默认 `public`（所有人公开）；可在设置中改为 `friends`。分享窗口可对单条覆盖。
- `GET /feed?scope=all`：所有 `visibility=public` 且作者 discoverable 的分享。
- `GET /feed?scope=friends`：好友的分享（public + friends）+ 自己的分享。
- 私信分享：`POST /messages/send` 仅好友；`direct_messages` 只存歌曲元数据与可选短文本；`GET /messages` 列表；`POST /messages/read` 标记已读。
- v1 不做点赞/评论；预留字段，v1.1 再加。分享/私信均限流。

## 七、口味偏好

- 客户端调用网易云官方 weapi `/api/tag/my/preference/get`（现有 `weapiPost`），取 `data.tagPreferenceVos`。
- 只上传 `{tagId, tagName, ratio}` 到 `POST /taste/update`；不上传 Cookie、不上传账号。
- 服务端 `user_tags` 存标签/占比；`GET /users/recommended?mode=taste` 按共享标签的 ratio 加权相似度排序，返回 `matchTags`。
- 无标签（未登录/接口空）时回落 `mode=active`，按最近活跃排序。
- 刷新时机：登录后、用户点“更新口味”、或距上次更新超过 7 天；不每次进页面调用。
- 展示：设置/在线服务页展示 top 标签；好友推荐行展示“共同口味：二次元 / 流行”。

## 八、一起听

- 只允许好友邀请；无房间码、无公开加入。
- 房主：从歌曲详情“更多”→“一起听”→选择好友→创建房间并发送邀请；房间最多 4 人；邀请 30 分钟过期。
- 受邀者：在“我的好友”页看到邀请横幅，进入 `together` 页接受/拒绝；接受即加入。
- 房主唯一写状态；`room_state.seq` 递增；`updated_at` 服务端时间；客户端用 `serverTime + RTT/2` 估算目标位置。
- 成员心跳 5–10s；60s 无心跳移出；房主 90s 无心跳房间结束；6h 无活动清理。
- 同步方式：房主在曲目/播放状态/seek 变化时上报，每 5s 心跳；客人 1.5s 拉取，曲目不同则 `playList+seekTo`，同曲漂移 >1200ms 则 seek，房主暂停则 `toggle`。
- 后台冻结：只能前台同步，回前台重同步；不做服务端音频转发。

## 九、发布/更新

- `manage.py release add --amr ... --appid ... --version ... --code ...`：SHA-256/size，拷到 `/var/www/bpncm/releases/<appid>/<code>.amr`，写 `releases`；`--disable` 下线。
- `releases/latest` 只返回更高 code；客户端 `BUILD_CODE` 严格小于才提示；服务端保留旧版本供回滚。
- 更新前把当前 .amr 留在 `/userdisk/Favorite/` 作为 last-known-good；失败可重装旧包（data 仍在）。

## 十、运维

- 每日 `sqlite3 .backup` + `.env` + zstd 到 `/var/backups/bpncm-*.tar.zst`，保留 14 天；`.env` 与 DB 同备。
- gunicorn/nginx 日志；不记录 Authorization/body/SN；`/health`；部署后从笔端无 `-k` 验证。
- 静态包原子替换；API 向后兼容；重启 gunicorn 约 1s 空窗可接受。
